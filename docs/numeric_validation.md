# 数值抽取 Python计算 与答案核对

当前知识库与索引不需要重建。新的 NumericEngine 在检索和年份过滤之后运行，仅从已召回文档补充相关原文，或读取实际候选表格。Python 负责解析确定格式、验证数据、执行 Decimal 运算并生成核验模板。Qwen 继续参与意图规划和语言组织，但不能替换系统计算的结果。

## 已支持的工具

- 收费条款：文/理/工/艺术类别基准学费、明确的优势学科上浮比例、住宿费预收标准；支持明确年限下 `(调整后学费 + 住宿费) × 年限`。数据与比例均来自原文，不固定年份或金额。没有年限时明确按一年合计；住宿费最终以实际条件结算。
- 师资条款：专任、外聘、折合教师和折合在校生的明确数值；外聘折算系数按 `(折合教师 - 专任教师) / 外聘教师` 反推，生师比按折合在校生除以折合教师复算，保留两位小数。如果原文提供生师比，则检查复算是否在0.01容差内。
- 招生选科：用实际列名匹配首选、再选、专业、计划字段，遍历完整表格；“不限”、单科、“或/任选”和“和/均须”等关系分别解释。跳过总计行，保留符合条件的每个专业、行号和计划数；存在多张候选表、重复专业、缺失值或未知且/或关系时拒绝汇总。

这些是有限的规则工具，不是任意自然语言计算器。新的表格口径、模糊范围、万元计数等未支持格式需要增加验证规则，不能依赖小模型猜测。通用表格计算路径仍依赖模型计划，虽然有字段、单位、年份和跨表检查，也不代表所有语义条件都已正确理解。

## 来源与答案验证

每个原文事实记录 field、raw_value、value、unit、quote、doc_id、evidence_id 和去空白文本中的 normalized_span。表格事实记录 row_id、table_id 和 cell_id，最终引用由这些实际来源生成。页码不会被当作师资人数，因为抽取规则要求数值紧邻对应字段；同一字段出现不同值时不自动选择一个。

当前答案核对采用严格回退：只有模型草稿去空白后与核验文本相同才直接采用；其他措辞一律回退到 Python 模板。这样也能拦截数字相同但标签互换的情况。该方法会牺牲语言灵活性，不是通用的语义等价判断。审计中的 model_draft 是未被采用的模型草稿，不应作为正确答案提交。

AnswerResult.numeric_verification 包含 verified、used_template、reason、model_draft 和 facts。缺少证据或不支持的数值问题返回 verified=false；普通非数值问答的该字段为空，不能据此宣称其所有附加数字均已验证。

## 验证与使用

```powershell
python -m pytest -q
python scripts/smoke_qa.py --output data/eval/numeric_qa_all.json
python app.py
```

批量测试时同时保存数值审计，CSV仍只有规定的三列：

```powershell
python scripts/batch_answer.py --input data/eval/questions.csv --output results.csv --audit-output data/eval/answer_audit.json
```

本机真实模型记录位于 data/eval/numeric_qa.json（前五题）和 numeric_qa_extended.json（费用合计、师资折算）。当前报告原文对应：学费6380元、住宿费预收1500元；四年合计31520元；选科筛选65人；专任2318人、外聘864人；反推系数0.5、复算生师比14.86:1。这些数值是本次资料的验证结果，不是运行时代码常量。测试修改原始数字后检查输出跟随变化，另覆盖冲突、缺失、标签互换、页码干扰、分母零和多表重复计数等反例。

这些样例通过不代表未知测试集准确率。院系范围、旧制度适用性、跨资料冲突、面积占比等场景仍应独立建立测试并逐项扩展工具。
