# 操作数角色、完整修复链与可归因重训

本轮先修改接口和验证，再训练。默认服务不自动启用适配器；未修改原始数据库或索引。

## 接口与测试

question_operand_roles 在明确表达中保留数值、单位、原文片段、位置、角色及精确性。角色包括总量、已完成量、剩余量、计划量；不为隐含表达猜角色。最终剩余量减法检查减数是否使用相应已完成量，并检查明确总量；同值的总量与已完成量可以合法得到0。多个不同已完成量或非确定数量不能据此猜测。

执行前对直接常数做角色预检查，在读取范围等错误发生时合并反馈。即使修复了第一个报错，也会重新校验完整计划。修复提示不再要求保留所有未报错的lookup，而是重新核对所有取值、角色、对象、周期和运算链。周期反馈包含冲突事实ID、原周期与乘数单位，仍不允许猜测换算。

全套测试333项通过，包括角色／位置、词序、计划与已完成量、合法零余量、重复数值、歧义拒答、多错误反馈、真实两轮服务修复及修复不完整继续拒答。

## 先测旧权重与新接口

interface_baseline/ 使用冻结V8 step_300在新接口下与基础模型配对运行54题。基础模型49/54；V8加新接口53/54，相对基础模型没有原正确题退步，错误数值为0。C02恢复40−8×4=8小时；NEW05恢复10−4=6学分。但NEW06从原V8正确变成拒答，因此还不能声称新接口对旧V8所有题均不退步，也不能把53/54当成新训练收益。

## 新数据

独立生成1200条训练、240条验证、240条测试，不抄写真实回归答案。数据最终审查按实际样本统计，而不只检查模板代码：

- 120条学分／学时剩余量均存在表格／正文重复总额、同单位总量／已完成量／计划量竞争。
- 40条合法零余量；61条已完成量纠错；42条同时包含范围和常数角色错误的修复。
- 10条真正进入比例任务的分母前置样本，消除原先题型索引奇偶性导致的覆盖落空。
- 周／月原文事实顺序随机；问题增加不计本次实际用量的计划工时。
- 保留字段、来源、人数费率、预算、绩点、拒答和旧能力样本。

角色覆盖见 role_coverage.json；参考计划、单位、来源、行集合和有序操作数均执行核验。训练与验证／测试使用不同资料实例及问法；这是合成留出集，不是新的人工作业盲评。旧真实失败题只作开发回归。

## 训练与完整链评测

基础Qwen3-0.6B重新开始，r=8、alpha=16、all-linear、BF16、学习率2.5e-5、两轮300次更新；不增加参数或轮数。微批量1、累积8，完成式JSON及结束标记监督，完整断点每25步保存，适配器每75步保存。

在训练前固定只比较150/300两个验证检查点，减少完整链评测开销。评测对照为基础模型＋新接口、冻结V8＋新接口、新权重＋同一新接口。合成评测从实际证据重新生成首轮提示，使用模型自己的首轮输出和执行器反馈，最多一次修复，不把数据中的教师错误计划喂给评测模型。

分别记录首轮正确、最终正确、修复尝试、修复成功、首轮被拒绝而修复后新增错误数值。仅在验证集选点，之后评估测试集与当前54题回归。对照检查既保留基础模型正确题，也检查相对V8的退步与新增错误；最终 attribution.json 区分旧V8加新接口和新训练权重的收益。若基础模型的两次运行输出不同，归因需复核，不能自动通过。
