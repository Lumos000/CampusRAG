## 代码入口

|模块|主要文件|职责|
|---|---|---|
|采集与导入|`crawl/crawler.py`、`ingest/pipeline.py`、`ingest/parsers.py`|公开资料采集、解析与导入|
|离线规范化|`database/normalization.py`|表格数值、单位、年份与合计行元数据|
|检索|`index/hybrid.py`、`index/bm25.py`|BM25、BGE、RRF 和重排|
|问答调度|`rag/service.py`|原始问题检索、路由、一次修复、答案和诊断|
|计划生成|`rag/planner.py`|真实 Schema/Facts、受限 JSON、步骤引用|
|正文计算|`rag/numeric.py`|正文 Facts、可选快捷规则和程序答案|
|执行校验|`database/query.py`|完整表格范围、字段/对象/单位校验和 Decimal 运算|
|模型与引用|`rag/generator.py`、`rag/citations.py`|本地 Qwen 推理及程序生成来源|

表内路径均相对 `src/campus_rag/`。应用入口为根目录 `app.py`，批量三列 CSV 入口为 `scripts/batch_answer.py`。
