# 检索后处理可靠性修复与回归记录

基线为 `10b9ceb`。本轮只修改5个已有运行时文件和新增1个测试文件；未更换模型、依赖、检索、数据库或索引，未微调。

## 确认的缺陷与修改

|文件|已复现的问题与修复|
|---|---|
|`tools/numbers.py`|提取问题中数值紧邻的真实单位和原文位置；名、位按人数绑定，年份不能充当人数。|
|`rag/numeric.py`|通用“奖励金额”错误合并不同标题下的对象；保留真实标题主体、原文与位置。补充明确总数、完成时长、上下界和门类量词；生均金额保留元/人。日期不当成时长。同主体冲突仍拒绝。|
|`database/query.py`|问题要求总额却只返回单人费率仍被放行；核对人数、运算量种和参与记录。人数相同的不同组不能去重漏算。支持与真实表值绑定的等级简称及并列名称，排除方向仍验证；保留区间行、单位和完整性限制。补充上下界和正文列举对象覆盖检查。|
|`rag/planner.py`|只展示真实Facts/字段的计划，提供已明确的用户常数、比较方向及上下界；命名对象A占B使用各自筛选，整表比例仍使用完整分母。|
|`rag/service.py`|“是否计入平均值”不因平均关键词进入运算；个人获奖及最终到账缺少资格/评审结果时明确拒答，公开申请条件仍可查询，“只按办法”不能绕过。|

## 验证方法和真实结果

- 新增24项合成正反例。冻结旧代码隔离运行：20失败、4通过；候选全套165通过。覆盖不同金额/标题、范围、周期、人数、排除、直接事实、申请条件和命名比例，并非复用测试答案。
- 先运行候选v1，再仅补充已复现的命名分母示例修复运行v2。两轮均完整运行12题、36题和16题，输出分别保存在 `data/eval/post_v2_fix_v1/` 与 `data/eval/post_v2_fix_v2/`，没有拼接最好答案。
- 每轮保留原金标副本、输入哈希、候选补丁、原始结果、三列CSV、诊断、逐题对照及评分。36题答案及引用与冻结版本逐字一致；新增正确数值题核对对象、算式、单位、范围和真实证据。
- 首次独立v2原结果和金标未覆盖。v2已用于定位与修复，本轮只报告公开后回归，不能称为新的独立泛化准确率。由同一助手核验，不是外部盲评。

## 尚未解决与下一步

- 开发36题原C01、C03、C08仍失败；本轮没有宣称它们已修复。具体原始计划及原因保留在逐题对照文件中。
- 已公开v2的C06、C07、C08：Facts已具备真实时长、学期、上下界，示例也包含必要操作数，但Qwen仍漏定义right，唯一一次修复也未补齐；拒答而不猜算。瓶颈已从抽取移到小模型计划生成。
- 普通文字仍有长篇原文和无关总则，核心要点正确不等于逐句精确相关；本轮未重写文字证据整理。
- 轻量约束检查不等于完备的自然语言语义证明；verified表示已通过当前校验，不能替代人工评测。
- 下一步优先离线分析剩余错误计划，单独试验更短、只含相关操作数的规划上下文；必须完整回归，有收益才保留。无需为本轮问题调整数据库或重建索引。尚无证据证明必须LoRA/QLoRA。
- 最终候选冻结后，另建从未参与调试的新测试集做独立评测；已公开v2不再承担该用途。
