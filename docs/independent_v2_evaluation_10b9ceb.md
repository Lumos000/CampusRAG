## 已确认的根因

1. **对象/字段绑定失败（3题）**：综合一二三等奖的简称没有匹配到真实表内奖项名。表内1000、700、400元均解析正确；规划缺少筛选，读入第四行单项奖100～300元的区间后被拒绝。不能把它误诊为原始数据缺失，也不能靠跳过区间行提高成绩。
2. **Facts表示和抽取不足（4题）**：V2C04的两个不同奖项均被标成“奖励金额”，200与100被误判冲突而删除；V2C06的“能够完成120小时”、V2C07的“共4学期”未被触发词接受；V2C08的8-10门范围及量词未表示。学期已在单位正则中，问题并非单纯缺该单位。
3. **计算语义漏检（1题，优先级最高）**：V2C05未要求13人的人数参与总额计算，生均金额也未表示为人均费率，单次lookup100元被当作合格结果。JSON、数值本身及来源都合法，问题答案仍然错误。
4. **路由与拒答理由（各1题）**：“是否计入平均学分绩点”被“平均”关键词触发为计算；个人获奖及到账问题仅因单位错误被偶然挡住，没有正确处理个人资格与评审结果边界。
错误主阶段计数：字段/对象绑定3，Facts抽取4，问题语义校验1，路由1，拒答原因1，共10题未通过。14道可回答题均召回金标证据，不代表检索上下文没有噪声，但本次主要失败发生在检索之后。
