# 索引加载 年份 导航表与完整问答验证

## 已实施

- 索引 JSONL 按文件物理行读取，避免正文 U+0085 等特殊换行分隔符破坏 JSON；加载时检查向量数量、维度和有限数值。
- 原问题中的明确年份优先于模型生成的时间条件，在 BM25、向量召回前过滤；结构化表格查询再次过滤。标题中的年份优先于发布日期。学年区间按标题的完整区间匹配，不按发布年份替代。不满足年份的资料不会作为回退候选。
- 明确要求招生章程、综合评价或教学质量报告时，以标题约束该类资料，避免跨主题干扰；同问多个类型时不使用单一标题约束。
- 导航表在未来 HTML 解析、当前索引检索、当前数据库计算三个位置识别。既有数据库与向量文件保留不动，通过运行时过滤拦截已入库的导航表，不需要为本次修复重建索引。
- 计算计划包含错误类型、未知运算或无效数值时进入修复/回退流程；计算题无法形成有效计划时明确拒答，不交由 Qwen 自行心算。事实题不再因模型误选 needs_text=false 而丢失正文证据。
- Reranker batch_size=4，以降低 6GB 显存环境下的瞬时内存占用；最终语言组织关闭长思考模式。

## 本轮人工检查

- 2038 年招生章程不在知识库：正确拒答，无引用。
- 图书馆借还手续：能检索正文并生成回答，导航菜单表不进入候选；答案还包含用户未要求的期限和违约金，应进一步核对适用版本。
- 2026 年综合评价筛选合计：年份约束有效，但小模型仍无法稳定生成正确字段和筛选条件，目前受控拒答，不能视作题目通过。
- 2026 年优势工科学费：检索到正确章程，但最终生成误把 5800 元基数当作最终标准，漏用上浮 10%；正确推导为 6380 元，住宿费预收 1500 元。该项不通过。
- 2023—2024 学年报告师资：检索文档的附录包含专任教师 2318 人、外聘教师 864 人，模型却将页码 40 当作人数。该项不通过。这里以当前抓取的报告原文为依据，不混用其他附件或版本的数据。
