# 阶段 1：正文数值表示

修改 `NumericEngine.text_facts()`：匹配时移除空白但保留字符映射，返回原证据中的准确引文和起止位置；记录主体、数值、单位、比较关系、条款、周期及包含后置适用条件的上下文。上下界不再作为同字段冲突而一并丢弃，不同主体和统计周期分开处理；同主体、条款、周期和比较关系出现冲突值时仍禁用。无单位数值仅接受明确绩点描述，页码、编号、近似值及没有明确数量的数据不补齐。

执行器增加有问题原文支持的常见时间、金额和面积常量单位；费率乘时长支持两个操作数顺序，仍由 Decimal 计算，并保留 Facts 中的原始比较关系及来源。没有进行数据库导入、规范化元数据迁移或索引重建。

新增回归使用不同对象和数值，覆盖上下限并存、周/月范围、跨行小时费率、无量纲绩点、条款与主体分离、后置适用条件、同范围冲突和复合单位运算。全量自动测试 86 项通过。

真实模型回归：12 题 12/12；36 题严格语义正确 19/36、数值正确 1/8，均保持基线。33 题答案、计算及引用完全一致；C01/C03/C04 的拒答错误发生变化，已逐题重新复核。真实结果、两次规划及执行日志见 `data/eval/stages/stage1/run1/`，逐题对照见同目录的 `comparison.json`。没有增加运行异常或错误作答；v2 未运行。

本阶段尚未修改规划示例、字段角色或问题语义约束。C01/C04 已有小时费率及绩点事实，但仍复制虚构表 7；C03 已有正确贷款上下限，但仍绑定还款示例表。表示层修复没有自动变成答案正确率改善，因此下一阶段必须修复示例与字段选择。使用本地 Qwen tokenizer 重建首次规划提示，9 道实际进入规划的题为 1222～5148 tokens（未计聊天模板少量开销），未发现超出 7168 配置的迹象。
