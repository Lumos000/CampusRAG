# 校园公开资料库适配与验收

2026年10月29日，默认库切换为“校园公开资料库”，内容为518篇南京邮电大学公开资料。使用基础Qwen3-0.6B，不启用微调适配器。

## 默认运行

在项目根目录、已准备模型的rag环境中运行：

```powershell
python scripts/check_database.py
python scripts/check_offline.py
python app.py
python scripts/batch_answer.py --input questions.csv --output results.csv --audit-output audit.json
```

默认配置为 `config/settings.json`，数据库为 `data/processed/campus_public/campus_public.db`，索引为 `data/processed/campus_public/index/`。交互、批量和离线检查入口均支持 `--config`；问答只读打开数据库，启动时核对数据库与索引的全部分块内容和来源字段。

输出CSV固定为UTF-8 BOM编码，列为“问题、答案、参考资料”。资料不足时保留明确说明，不生成虚构引用。正式验收应在准备完成后断开网络再执行相同命令。

## 数据切换与重建

本次把已验证518篇快照复制到正式名称下，保留原497篇基线库及旧518篇快照，没有重新采集、重新分块或重算向量。新旧518篇数据库、索引记录和向量文件的SHA256逐一相同，原497篇数据库哈希未变。切换记录为本地 `data/processed/campus_public/activation_report.json`；目录内复制的旧构建报告保留历史构建路径，以切换记录和当前settings为准。

新机器需准备模型、原始资料、原497篇数据库及两份清洗清单，再按 [数据集说明](college_database.md) 使用 `config/dataset_campus_public.json` 构建。目标目录必须不存在；已有默认库时，可指定全新输出目录验证。固定配置检查518篇数量及必需学院来源，不会自动覆盖原库。

数据库、原始资料和向量属于本地生成物，不随Git提交。历史文件名和评测快照不改名，以保留既有实验的来源记录；当前默认库名和运行配置不再使用v3。

## 问答适配

- “计算机学院”等名称不再触发“计算”路由；单纯询问学分、学时采用原文查询，明确求和、比较或计算仍由结构化执行器处理。
- 学分、学时查询要求检索资料中有对应数值和量纲，不能用无关名单计数替代。新增学分、学时的正文事实解析、单位规范化及结果单位检查。
- 本科、硕士、博士专业列举优先保留检索中明确出现该专业类别的资料，避免仅因微专业文件标题较长就选错文档。
- 明确指定的规则文件、常见问题和问答资料可以在同一文档内补取正文。按实际章节或问题分段，保留办理步骤、前提和例外，继续使用真实数据库来源。
- 保留原有跨文件查询改动及操作数配对校验。未扩展整份学生手册，以避免其中不同办法的条款相互混用。
- 模型调用实际检查输入token预算，输出预留同时受模型位置上限约束。超预算不静默截断证据条件；普通文字路径返回缩小问题范围的说明，计算路径可返回计划校验不足说明。

## 验证方法

修改前工作区263项自动测试通过。补充路由、量纲、来源、上下文和对照入口等回归检查后，提交前完整282项自动测试全部通过。

本地实际验证采用默认配置，调用正式 `scripts/batch_answer.py`，覆盖任务书四例、原八道校园问答样例及已公开36题开发回归。输入问题与金标分离；金标不传入RAGService。推理进程禁止socket连接并启用本地离线加载。该测试属于开发回归，不是新的独立盲测；没有读取新封存题集。

实际运行原始结果保存在本地 `data/collections/campus_public_acceptance_20261029_release/`，包含三列CSV、结构化审计、逐题诊断和运行记录。最终逐题核对及剩余问题以该目录的 `review.json` 为准。此前候选及扩展回归保留在相邻的 `campus_public_acceptance_20261029/` 与 `_final/`，不把不同候选的最好答案拼接成成绩。

随代码提交的 [验收摘要与逐题记录](../data/eval/campus_public/verified_release.json)、[固定问题CSV](../data/eval/campus_public/acceptance_questions.csv)及[三列答案CSV](../data/eval/campus_public/acceptance_answers.csv)保留此次单次运行结果。摘要中的源码哈希统一按UTF-8、LF换行计算，便于不同Git检出环境核对；数据库按原始文件字节计算哈希。

## 使用边界

518篇资料并不代表全校全部业务已覆盖，136篇仍缺少发布日期；有年份的问题继续执行年份约束。未标明适用版本的咨询不能承诺使用的都是当前有效政策。扫描PDF、复杂表格和新问题仍可能需要人工核实。自动测试和已公开样例通过不能替代未知题准确率。

课程实践报告仍应补充实际环境、所承担模块、可信测试与对照实验、失败案例、引用与资料时效，以及最终三列CSV。代码适配不代替最终报告与答辩准备。
